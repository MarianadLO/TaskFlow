TaskFlow

O TaskFlow é uma aplicação de gerenciamento de tarefas desenvolvida com foco no estudo de desenvolvimento front-end.

O projeto permite criar, organizar e acompanhar tarefas por categorias, além de oferecer recursos como filtros, prioridades, estatísticas e acompanhamento do progresso das atividades.

Seu principal objetivo é consolidar conhecimentos em HTML, LESS, JavaScript e automação de tarefas com Grunt, simulando um projeto real.

Funcionalidades:

✓ Criar tarefas
✓ Excluir tarefas
✓ Marcar tarefas como concluídas
✓ Filtrar por categoria
✓ Buscar tarefas
✓ Definir prioridade
✓ Visualizar estatísticas
✓ Barra de progresso
✓ Dark Mode
✓ Persistência de dados com Local Storage

Tecnologias utilizadas:

HTML5
LESS
JavaScript (ES6+)
Grunt
Git
GitHub

Conceitos praticados:

Manipulação do DOM
Eventos JavaScript
Arrays e Objetos
Funções
Local Storage
Responsividade
Organização de arquivos
Automação de tarefas
Versionamento com Git

Aprendizados:

Durante o desenvolvimento deste projeto foram praticados conceitos importantes de JavaScript, como manipulação do DOM, gerenciamento de eventos, filtragem de dados e armazenamento local.

Além disso, o projeto permitiu aprofundar conhecimentos em LESS para organização dos estilos e Grunt para automação de tarefas de desenvolvimento.
