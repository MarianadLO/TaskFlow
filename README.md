# TaskFlow

🇺🇸 English

TaskFlow is a task management application developed as a front-end learning project.

The application allows users to create, organize, and track tasks through categories, priorities, filters, and progress tracking features.

The main goal of this project is to strengthen front-end development skills while simulating a real-world application using HTML, LESS, JavaScript, and task automation with Grunt.

## Features

* Create tasks
* Delete tasks
* Mark tasks as completed
* Filter tasks by category
* Search tasks
* Set task priorities
* View task statistics
* Progress tracking
* Dark mode
* Data persistence with Local Storage

## Technologies Used

* HTML5
* LESS
* JavaScript (ES6+)
* Grunt
* Git
* GitHub

## Concepts Practiced

* DOM Manipulation
* Event Handling
* JavaScript Functions
* Arrays and Objects
* Local Storage
* Responsive Design
* Project Structure Organization
* Task Automation
* Git Version Control

## Learning Outcomes

During the development of this project, several important front-end concepts were practiced, including DOM manipulation, event handling, data filtering, and local data persistence.

The project also provided hands-on experience with LESS for stylesheet organization and Grunt for automating development workflows.

## Future Improvements

* Edit existing tasks
* Task deadlines and reminders
* Advanced filtering options
* Drag-and-drop task organization
* User authentication
* Cloud data synchronization

Task management application built to practice front-end development concepts and workflow automation.

# TaskFlow
🇧🇷 Português

O TaskFlow é uma aplicação de gerenciamento de tarefas desenvolvida com foco no estudo de desenvolvimento front-end.

O projeto permite criar, organizar e acompanhar tarefas por categorias, além de oferecer recursos como filtros, prioridades, estatísticas e acompanhamento do progresso das atividades.

Seu principal objetivo é consolidar conhecimentos em HTML, LESS, JavaScript e automação de tarefas com Grunt, simulando um projeto real.

Funcionalidades:

✓ Criar tarefas
✓ Excluir tarefas
✓ Marcar tarefas como concluídas
✓ Filtrar por categoria
✓ Buscar tarefas
✓ Definir prioridade
✓ Visualizar estatísticas
✓ Barra de progresso
✓ Dark Mode
✓ Persistência de dados com Local Storage

Tecnologias utilizadas:

HTML5
LESS
JavaScript (ES6+)
Grunt
Git
GitHub

Conceitos praticados:

Manipulação do DOM
Eventos JavaScript
Arrays e Objetos
Funções
Local Storage
Responsividade
Organização de arquivos
Automação de tarefas
Versionamento com Git

Aprendizados:

Durante o desenvolvimento deste projeto foram praticados conceitos importantes de JavaScript, como manipulação do DOM, gerenciamento de eventos, filtragem de dados e armazenamento local.

Além disso, o projeto permitiu aprofundar conhecimentos em LESS para organização dos estilos e Grunt para automação de tarefas de desenvolvimento.


Aplicação de gerenciamento de tarefas desenvolvida para praticar conceitos de desenvolvimento front-end e automação de fluxo de trabalho.
